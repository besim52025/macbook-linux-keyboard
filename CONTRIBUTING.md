# Contributing

Most valuable contributions:

1. **New "Tested on" rows** — model / distro / display server / layout. One-line PRs welcome.
2. **New layout worked examples** — `docs/layouts/<layout>.md` following the Turkish Q template.
3. **Confirming the Debian `keyd.rvaiya` rename** across Debian versions.
4. **Fixing inaccuracies** — open an issue with `scripts/diagnose.sh` output.

## Guidelines

- **Method-first, not model-first.** General fix, then model-specific quirks.
- **Be explicit about what did not work** and why.
- **Include versions** (distro release, keyd version, kernel, GNOME/KDE/Sway version).
- **Redact serial numbers / MAC addresses** before pasting `diagnose.sh` output.
